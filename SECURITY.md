# Data safety

This repository contains synthetic portfolio data only.

Do not submit real customer exports, personal data, credentials, employer data, confidential files, or proprietary marketplace specifications to this repository.

The v1 pipeline rejects input columns that appear to contain names, addresses, email addresses, phone numbers, card data, payment tokens, or similar personal fields. This safeguard is intentionally conservative and is not a substitute for a privacy review.

If sensitive data is found in a fork or issue:

1. Stop processing it.
2. Do not commit or upload it.
3. Remove it from working copies and generated outputs using an approved secure procedure.
4. Rotate any exposed credentials.
5. Contact the data owner through a private channel.
