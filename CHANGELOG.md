# Changelog

All notable project changes are recorded here.

## [0.1.0] - 2026-09-06

### Added

- Configuration-driven adapters for three fictional EC sales CSV schemas.
- Deterministic validation, normalization, duplicate handling, aggregation, and reconciliation.
- Portable CSV/JSON pipeline with an installable `ec-sales` command.
- Japanese and English seven-sheet demonstration workbooks generated from one report model.
- Eight dependency-free tests and Python 3.11–3.13 CI.
- Data-safety, licensing, compatibility, distribution, and publication-audit documentation.

### Boundaries

- Sample data is wholly synthetic.
- The portable command produces CSV and JSON outputs.
- Workbook generation remains a managed-development workflow and is distributed only as a verified demonstration artifact.
